# Chase and Jump Game

A fun, browser-based platform game built as part of the freeCodeCamp curriculum. Guide the player across platforms, jump between obstacles, and reach all three checkpoints to finish.

## How to Play

1. Open `index.html` in a web browser.
2. Select **Start Game**.
3. Use the **Left** and **Right Arrow** keys to move.
4. Press **Space** or the **Up Arrow** to jump.
5. Reach each yellow checkpoint in order to complete the game.

## About the Project

This project was created while working through freeCodeCamp's [Learn Intermediate OOP by Building a Platformer Game](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures-v8/learn-intermediate-oop-by-building-a-platformer-game/step-1) curriculum. It was a really enjoyable way to practice JavaScript and bring game mechanics to life in the browser.

The game uses the HTML canvas to draw the player, platforms, and checkpoints. Its JavaScript code models those elements with classes and handles movement, gravity, platform collisions, and checkpoint progress.
